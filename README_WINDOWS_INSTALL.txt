================================================================================
   СИСТЕМА ПРОВЕРКИ ЗНАНИЙ И АТТЕСТАЦИИ «ЭКЗАМЕН» (ЛОКАЛЬНАЯ ВЕРСИЯ WINDOWS)
================================================================================

Данный пакет позволяет запустить систему автономно на любом компьютере с ОС Windows
без подключения к интернету и без необходимости установки старых драйверов BDE.

--------------------------------------------------------------------------------
1. БЫСТРАЯ УСТАНОВКА В 1 КЛИК:
--------------------------------------------------------------------------------
1) Распакуйте архив с программой в любую удобную папку (например, C:\Ekzamen).
2) Запустите файл: Setup_Windows.bat
   - Скрипт проверит наличие среды Node.js (если нет — предложит установить);
   - Установит все необходимые модули базы данных;
   - Скомпилирует автономный сервер;
   - Создаст ярлык «Экзамен - Охрана труда» на вашем Рабочем столе.

--------------------------------------------------------------------------------
2. ЕЖЕДНЕВНЫЙ ЗАПУСК:
--------------------------------------------------------------------------------
- Двойной клик по ярлыку на Рабочем столе ИЛИ по файлу «Запустить_Экзамен.bat».
- Программа автоматически откроется в вашем браузере по адресу:
  http://localhost:3000

--------------------------------------------------------------------------------
3. РАБОТА ПО ЛОКАЛЬНОЙ СЕТИ ПРЕДПРИЯТИЯ (СЕТЕВОЙ РЕЖИМ):
--------------------------------------------------------------------------------
Вы можете запустить сервер на одном главном компьютере (или сервере организации), 
а сотрудники могут проходить тестирование со своих рабочих мест:
- Узнайте IP-адрес главного компьютера (в командной строке: ipconfig).
- На компьютерах сотрудников откройте браузер и введите:
  http://<IP-АДРЕС_СЕРВЕРА>:3000   (например: http://192.168.1.50:3000)
- Все протоколы и результаты сдачи будут централизованно сохраняться 
  в единой базе данных на главном компьютере!

--------------------------------------------------------------------------------
4. ОСТАНОВКА СЕРВЕРА:
--------------------------------------------------------------------------------
Для остановки локального сервера запустите файл:
«Остановить_Экзамен.bat» или закройте окно командной строки.
