# 🛡️ Система проверки знаний по технике безопасности и охране труда (Safety Test Pro)

Локальное кроссплатформенное веб- и десктопное приложение для автоматизированного обучения, тренировки, аттестации и ведения журналов проверки знаний сотрудников по **охране труда (ОТ)**, **пожарной безопасности (ПБ)**, **электробезопасности (ЭБ)**, **высотным работам** и **оказанию первой доврачебной помощи**.

---

## 🛠 Технологический стек

- **Frontend**: React 19, TypeScript, Tailwind CSS, Lucide Icons, Canvas-Confetti, Motion.
- **Backend / API**: Node.js, Express.js (REST API).
- **База данных**: Автономная реляционная **SQLite** (`safety_test.sqlite` на базе WASM `sql.js` с сохранением на локальный диск).
- **ИИ-интеграция**: Google Gemini 2.5 Flash (через `@google/genai`) для интеллектуального распознавания нестандартных билетов и таблиц.
- **Модули парсинга документов**: `pdf-parse`, `mammoth` (Word .docx), `xlsx` (Excel .xlsx, .xls, .csv).
- **Сборка и компиляция**: Vite 6, ESBuild, TSX.

---

## 🌟 Ключевые возможности

### 1. Режимы тестирования сотрудников
- **Ввод данных**: Обязательная фиксация Ф.И.О. сотрудника и подразделения/отдела.
- **Режим «Тренировка»**:
  - Свободный темп без ограничения времени.
  - Мгновенная проверка ответа с подсветкой вариантов (зелёный — верно, красный — ошибка).
  - Отображение нормативного обоснования со ссылками на ГОСТ, ПУЭ, ПОТ и правила пожарной безопасности.
  - Возможность повторного прохождения без штрафов.
- **Режим «Экзамен (Аттестация)»**:
  - Строгий экзаменационный режим без подсказок и пояснений во время прохождения.
  - Интерактивный навигатор по номерам вопросов (с индикацией отмеченных/неотмеченных).
  - Таймер времени сдачи.
  - **Критерий сдачи**: Экзамен считается сданным **только при 100% правильных ответов** (все вопросы решены верно).
- **Официальный протокол проверки знаний**:
  - Генерация и вывод на печать стандартизированного экзаменационного листа.
  - Поля для подписей экзаменуемого и членов комиссии по проверке знаний.
  - Праздничная анимация конфетти при успешной аттестации.

---

### 2. Административная панель (Кабинет инженера по ОТ)
- **Безопасность**: Защита входа паролем (по умолчанию: `admin`).
- **Управление темами и направлениями**:
  - Создание, редактирование и удаление тематических разделов.
  - Выбор семантических иконок и просмотр статистики по вопросам.
- **Визуальный конструктор вопросов**:
  - Создание и редактирование вопросов любого уровня сложности.
  - Одиночный выбор (радиокнопки) и множественный выбор (чекбоксы).
  - Загрузка иллюстраций/схем (встроенный файл до 3 МБ через Base64 или внешний URL).
  - Поле нормативного пояснения с цитатами из регламентов.
- **Журнал протоколов и аналитика**:
  - Полная история всех попыток с фильтрами по статусу («Сдан» / «Не сдан») и поиском по фамилии.
  - Детальный аудит ответов кандидата по каждому вопросу.
  - Экспорт журнала аттестаций в формате **Excel (CSV)**.
- **Резервное копирование**:
  - Полный экспорт базы данных в стандартизированный `.json` файл.
  - Функция безопасного сброса базы к заводским эталонным данным.

---

### 3. Интеллектуальный мультиформатный импорт вопросов
Приложение поддерживает автоматическое распознавание вопросов из любых популярных форматов:
- 📄 **PDF-файлы (`.pdf`)**: извлечение текста и билетов из методичек, сканированных инструкций и приказов.
- 📝 **Word-документы (`.docx`, `.doc`)**: парсинг списков, билетов и форматированных тестов.
- 📊 **Excel-таблицы (`.xlsx`, `.xls`, `.csv`)**: чтение строк и колонок (*Тема*, *Вопрос*, *Варианты 1-4*, *Правильный ответ*, *Пояснение*).
- 📋 **Текстовые файлы (`.txt`, `.md`) и ручная вставка из буфера**: моментальная вставка скопированных фрагментов.
- 📦 **JSON-файлы (`.json`)**: структурированный перенос данных.

**Два движка парсинга**:
1. 🤖 **Умный ИИ-анализ (Gemini 2.5 Flash)**: извлекает темы, вопросы, варианты и правильные ответы даже из неструктурированного текста и сложных таблиц.
2. ⚡ **Автономный офлайн-парсер**: работает мгновенно без интернета по интеллектуальным регулярным выражениям (распознает маркеры `1.`, `a)`, `+)`, `(верно)`, `[x]` и др.).

## 🚀 Инструкция по установке и запуску

### Требования
- **Node.js** v18.0+ или v20.0+
- Менеджер пакетов **npm**

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки (Dev Server)
```bash
npm run dev
```
Приложение откроется по адресу: **`http://localhost:3000`**

### 3. Сборка и запуск продакшен-версии
```bash
npm run build
npm start
```

## 🔌 Справочник REST API

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/api/health` | Проверка доступности и работоспособности сервиса |
| `GET` | `/api/topics` | Получение списка всех тем с количеством вопросов |
| `POST` | `/api/topics` | Создание нового раздела |
| `PUT` | `/api/topics/:id` | Редактирование темы |
| `DELETE` | `/api/topics/:id` | Удаление темы и всех привязанных к ней вопросов |
| `GET` | `/api/questions` | Получение всех вопросов (с фильтрацией `?topic_id=`) |
| `POST` | `/api/questions` | Создание нового вопроса с вариантами ответов |
| `PUT` | `/api/questions/:id` | Обновление вопроса и вариантов ответов |
| `DELETE` | `/api/questions/:id` | Удаление вопроса |
| `POST` | `/api/parse-any-file` | Мультиформатный парсинг файлов (PDF, Word, Excel, TXT, Clipboard) |
| `POST` | `/api/save-imported-questions` | Массовое сохранение распознанных вопросов в базу данных SQLite |
| `GET` | `/api/results` | Получение журнала сдачи тестов и экзаменов |
| `POST` | `/api/results` | Фиксация результата прохождения теста/экзамена |
| `GET` | `/api/results/export` | Выгрузка журнала результатов в файл CSV (Excel) |
| `GET` | `/api/stats` | Сводная аналитика платформы (темы, вопросы, аттестации, % сдачи) |
| `POST` | `/api/auth/verify` | Проверка пароля администратора |
| `GET` | `/api/export-json` | Полный бэкап базы данных в файл JSON |
| `POST` | `/api/reset-db` | Восстановление базы к эталонному состоянию |

## 📦 Сборка в Windows Desktop-приложение (.EXE)

Для создания автономного `.exe` файла для установки на компьютеры учебных классов:

1. Установите Electron:
   ```bash
   npm install --save-dev electron electron-builder
   ```
2. Создайте файл запуска `electron-main.js`:
   ```javascript
   const { app, BrowserWindow } = require('electron');
   const path = require('path');

   function createWindow() {
     const win = new BrowserWindow({
       width: 1280,
       height: 900,
       title: 'Система проверки знаний по ТБ',
       webPreferences: { nodeIntegration: true }
     });
     win.loadURL('http://localhost:3000');
   }

   app.whenReady().then(createWindow);
   ```
3. Запустите сборку дистрибутива:
   ```bash
   npm run build
   npx electron-builder --win
   ```
   Готовый инсталлятор `.exe` будет сформирован в директории `dist/`.

## 📄 Спецификация формата JSON для прямого импорта

Файлы `.json` для прямого импорта без парсинга должны соответствовать структуре:

```json
{
  "topics": [
    {
      "title": "Пожарная безопасность",
      "description": "Правила противопожарного режима",
      "icon": "flame"
    }
  ],
  "questions": [
    {
      "topic_title": "Пожарная безопасность",
      "text": "Каким огнетушителем разрешено тушить электроустановки до 1000 В?",
      "explanation": "Углекислотными (ОУ) или порошковыми (ОП) с расстояния не менее 1 метра.",
      "image_url": null,
      "is_multiple_choice": false,
      "options": [
        { "text": "Углекислотным (ОУ) или порошковым (ОП)", "is_correct": true },
        { "text": "Водным огнетушителем (ОВ)", "is_correct": false },
        { "text": "Воздушно-пенным (ОВП)", "is_correct": false }
      ]
    }
  ]
}
```

## 🐍 Миграция из унаследованных Win32 систем (Python скрипт)

Для извлечения вопросов из старых систем проверки знаний (базы `.dbf`, `.ini`, `.xml`, `.mdb` или текстовые дампы):
1. В корне проекта доступен скрипт `extract_legacy.py`:
   ```bash
   python extract_legacy.py --input /path/to/legacy_tests_folder --output safety_test_import.json
   ```
2. Полученный `safety_test_import.json` загружается в админ-панели в один клик.

## 🗄 Схема базы данных SQLite (`safety_test.sqlite`)

- **`topics`**: `id`, `title`, `description`, `icon`, `created_at`
- **`questions`**: `id`, `topic_id`, `text`, `image_url`, `explanation`, `is_multiple_choice`, `created_at`
- **`options`**: `id`, `question_id`, `text`, `is_correct`
- **`test_results`**: `id`, `employee_name`, `department`, `topic_id`, `mode`, `score`, `total_questions`, `passed`, `time_spent_seconds`, `answers_json`, `created_at`
